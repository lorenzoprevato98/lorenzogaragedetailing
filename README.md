# Lorenzo Garage Detailing

Sito web ufficiale di Lorenzo Garage Detailing (Torreglia, Padova).

## Sviluppo e Minificazione Asset

I file sorgente leggibili e formattati sono `style.css` e `script.js`.
Per generare le versioni ottimizzate per produzione e SEO (`style.min.css` e `script.min.js`), eseguire:

```bash
npm run minify
# oppure
npm run build
```

Le pagine HTML caricano i file minificati per massimizzare la velocità di caricamento (PageSpeed/Core Web Vitals) e superare i controlli di performance (SEMrush, Lighthouse).
